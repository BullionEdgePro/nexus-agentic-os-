# SFS Workflow Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A live "Workflow audit" page in Nexus that draws the SFS boss's 20-step AI-agent workflow with each step's honest status and real numbers, plus five charts, from SFS's own data only.

**Architecture:** One read-only endpoint `GET /api/organizations/:slug/workflow-audit?days=7|30|90` (behind the existing `requireTenantScope`) calls one database read that counts the evidence inside `withTenant`. A pure shared module holds the 20-step definition, the status rules and the business registry. One Cream-kit page renders the lanes, tiles, charts, funnel and compliance table.

**Tech Stack:** Postgres (RLS, `withTenant`), Hono API, Next.js 14 / React 18 web, the Cream kit (`apps/web/app/kit`), node:test with tsx.

**Spec:** `docs/superpowers/specs/2026-11-02-sfs-audit-design.md` (approved 2 Nov 2026).

## Global Constraints

- Every number comes from Nexus's real data for the business; nothing invented, no literal series, no typed-in figures.
- A missing value is never drawn as 0: no reply → an empty "no replies" bar; measured zeros show as "0".
- Not-tracked steps show no figures; colleagues' individual figures are never listed.
- Periods: 7 / 30 / 90 days only (anything else → 400); opens on 30; days and weeks are the business's own (`organizations.timezone`, Asia/Dubai for SFS); weeks start Monday; today included up to now and drawn `partial`.
- Funnel shares: "x of y" when the step before is under 20, a whole percentage from 20 up.
- The boss's tags, names and subtitles are copied exactly as in spec §4.2.
- Access: admins any business with a workflow (reached from Business HQ); staff only their own business (sidebar item only when their business has a workflow); other businesses' staff get `requireTenantScope`'s 403.
- No new table, no migration.
- Cream kit, Warm Night and 375 px phone; motion only inside `prefers-reduced-motion: no-preference`.
- Commit locally only on branch `sfs-audit` (worktree `C:\CLAUDE CODE\nexus-sfs-audit`); never push or deploy without the owner's "Deploy it".
- `apps/web/lib/api.ts` has CRLF line endings — edit it with a CRLF-aware script.

## Review Focus

1. **A chat routed to SFS through a shared number** (`routed_organization_id` = SFS) counts for SFS, not for the number's owner — pinned in Task 2's database test.
2. **A conversation opened by SFS with no customer message yet** (an outbound template nobody answered) is not a new lead and has no reply time — pinned in Task 2's database test.
3. **Free-text lead sources** ("Bayut", " bayut ", "BAYUT") are one source, grouped by `lower(trim(...))`, and a long source name never widens a card — pinned in Task 2's database test and Task 6's render test.
4. **Switching 7 → 90 → 30 quickly** never shows an older period's answer under the newer pill — pinned in Task 7's page source test (a request counter).
5. **Staff of a business without a workflow opening `/deck/workflow` by URL** get "No workflow is set up for this business yet.", not an error — pinned in Task 7's render test.

All reads in one `withTenant(organizationId, …)`.
